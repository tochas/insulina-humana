# Lista de comprobación del viernes

El nombre de esta lista responde a la solicitud del proyecto; no establece una fecha oficial de entrega.

- [ ] Laptop cargada y con suficiente espacio.
- [ ] Cargador y conexión eléctrica comprobados.
- [ ] Control Xbox disponible.
- [ ] Cable USB o adaptador y batería del control.
- [ ] Edge o Chrome instalado y aceleración gráfica disponible.
- [ ] Carpeta completa del museo, con `dist`, `runtime` y `scripts`.
- [ ] INICIAR_MUSEO.bat abre la experiencia.
- [ ] CERRAR_MUSEO.bat detiene solo el servidor del museo.
- [ ] PWA instalada en esta laptop, si se usará el icono.
- [ ] Indicador OFFLINE PREPARADO antes de quitar la red.
- [ ] Monómero y hexámero cargan desde modelos locales.
- [ ] Cadena A de 21 y B de 30 posiciones visibles.
- [ ] Tres puentes del reto identificados correctamente.
- [ ] Dos zinc visibles en la estación correspondiente.
- [ ] Audio y subtítulos comprobados; volumen adecuado al salón.
- [ ] Mando real probado y calibrado con palancas en reposo.
- [ ] Mouse y teclado preparados como alternativa.
- [ ] Modo offline comprobado en la laptop: quitar Wi-Fi y recargar.
- [ ] Ficha técnica impresa y copia PDF local.
- [ ] USB con ZIP y carpeta de respaldo.
- [ ] Resolución 1366 × 768 o 1920 × 1080 revisada.
- [ ] Pantalla completa y tamaño de texto legibles a distancia.
- [ ] Reinicio para siguiente visitante probado varias veces.
- [ ] Modo museo y forma de detenerlo conocidos.
- [ ] Dos integrantes asignados al primer turno del stand.
- [ ] Todos ensayaron guion, preguntas y aplicación biomédica.
- [ ] Rúbrica real de Classroom consultada cuando esté disponible; sin porcentajes inventados.
